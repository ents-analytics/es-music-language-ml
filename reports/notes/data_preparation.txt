--UNDERSTANDING 'FREQ'--
* This is the number of times a value appears in that column.
* This is for object (categorical) columns.
* For numerical columns, there are statistical summaries that are provided
* Exception to this is if an int (1) were stored as "1". Pandas would treat that as a categorical object. This would need to be fixed during the data cleansing process.

--UNDERSTANDING 'FREQ' IN THE CONTEXT OF CHART DATA--

if Artist A released 'Te Amo' in 2010 and then Artist A re-released 'Te Amo' in 2020, but another artist, Artist B, released a completely different song with the same name, 'Te Amo', in 2024:

The freq for 
- song would be 3
- artist would be 2
- weeks-on-board would be irrelevant for 'freq' since it is a numerical and not categorical value
